# Domain Collector

Расширение для Chrome и Edge на Manifest V3, версия 1.1.2. Сохраняет домены прямых посещений и фоновых обращений страниц локально в профиле браузера. Не отправляет собранные данные в сеть и не использует сторонние библиотеки.

## Установка

1. Распакуйте ZIP и сохраните папку `domain-collector` в постоянном месте.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку `domain-collector`, в которой лежит `manifest.json`.
5. Закрепите «Мои домены» на панели расширений. Откройте сайт и нажмите значок расширения.

## Что учитывает расширение

- Сбор начинается после установки;
- Расширение сохраняет имя хоста, отдельные счётчики прямых посещений и фоновых обращений, общий счётчик и время первого/последнего обращения. Например, `mail.example.com` и `example.com` создают отдельные записи. IP-адреса и `localhost` также учитываются.
- Фоновые обращения включают доступные через API браузера запросы вкладок: API/fetch/XHR, скрипты, изображения, стили, шрифты, медиа, встроенные фреймы и подключения WebSocket. Например, открытие `example.com` может добавить `api.example.com`, `cdn.example.com` и сторонний домен аналитики. Расширение учитывает запросы и к основному хосту сайта.
- Расширение фиксирует начало запроса, поэтому фоновые обращения могут включать неудачные попытки и предварительную загрузку ресурсов. При перенаправлении одного запроса на другой хост оно учитывает каждое доступное событие. Счётчик WebSocket учитывает подключения, а не отдельные сообщения.
- Расширение пропускает запросы без связи с вкладкой (`tabId = -1`), в том числе часть запросов service worker, внутренние страницы браузера и режим инкогнито. Браузер скрывает некоторые служебные запросы; расширение не собирает DNS-запросы и трафик других программ. Для основной страницы оно учитывает только конечный домен подтверждённого перехода.
- Не сохраняет пути, параметры URL, заголовки запросов, тела запросов или содержимое страниц. Данные о косвенных обращениях до обновления недоступны.
- Поиск и сортировка помогают выбрать записи. TXT, CSV и JSON экспортируют текущий отфильтрованный список. Очистка удаляет весь список; пауза сохраняет накопленные данные.
- Данные остаются при перезапуске браузера. Удаление расширения удалит его локальные данные. Экспортируйте список перед удалением.
- Браузер ограничивает объём локального хранилища расширения. При ошибке сохранения счётчик на значке окрашивается красным; проверьте сообщение в окне расширения.
